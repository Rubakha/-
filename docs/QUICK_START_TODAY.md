## 2️⃣ ПОЛУЧИТЬ CLAUDE API KEY (5 минут)

### Действие:
```
1. Перейди: https://console.anthropic.com/
2. Логин / Регистрация (email)
3. Подтверди email (письмо в Gmail/Яндекс)
4. Вернись на console.anthropic.com
5. Слева: API Keys
6. Нажми: Create Key
7. Скопируй ключ (выглядит: sk-ant-v0-XXXX...)
8. Сохрани в документ
```

### Что потом:
```
KEY → .env файл
env: CLAUDE_API_KEY=sk-ant-v0-XXXX...
```

## 3️⃣ ПОЛУЧИТЬ GOOGLE SHEETS KEY (7 минут)

### Действие:
```
1. Перейди: https://console.cloud.google.com/
2. Создай новый проект: "AlisaLetters"
3. Включи Google Sheets API:
   - Search: "Google Sheets API"
   - Enable (нажми)
4. Создай Service Account:
   - Menu → Service Accounts
   - Create Service Account
   - Name: "alisa-letters"
   - Create and Continue
5. Создай ключ:
   - Keys tab → Add Key → JSON
   - Скачается JSON файл
6. Скопируй ВЕСЬ текст из JSON
7. Сохрани в документ
```

### Что потом:
```
JSON → .env файл
env: GOOGLE_SHEETS_KEY={полный JSON текст}
```
