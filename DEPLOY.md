# 🚀 Выгрузка бота на Render — пошагово

## ШАГ 1. Подготовка репозитория GitHub

### 1.1. Создай репозиторий на GitHub

1. Перейди на github.com → New repository
2. Назови его `alisa-nevskaya-bot` (или как хочешь)
3. Описание: "Telegram-бот для продажи персональных писем"
4. Public (чтобы Render мог читать)
5. **Не** инициализируй README, .gitignore, license — добавим сами

### 1.2. Клонируй репо локально

```bash
git clone https://github.com/ТВО_ЮЗЕР/alisa-nevskaya-bot.git
cd alisa-nevskaya-bot
```

### 1.3. Распакуй архив `alisa_bot_2026.zip`

Распакуй содержимое папки `alisa_bot/` в корень репозитория. Должны быть файлы:

```
├── README.md
├── bot_best.py
├── ai_assistant.py
├── requirements.txt
├── render.yaml
├── Procfile
└── .env.example
```

### 1.4. Создай `.gitignore`

```bash
cat > .gitignore << 'EOF'
.env
__pycache__/
*.pyc
*.pyo
*.egg-info/
.venv/
venv/
data/
.DS_Store
EOF
```

### 1.5. Коммит и пуш

```bash
git add .
git commit -m "Initial commit: Alisa Nevskaya bot"
git branch -M main
git push -u origin main
```

Готово. Репо на GitHub с твоим кодом.

## ШАГ 2. Регистрация на Render

### 2.1. Перейди на render.com

1. Sign up с GitHub-аккаунтом (это проще — сразу даст доступ к репозиториям)
2. Авторизуйся

### 2.2. Подключи GitHub

Dashboard → Connect Git → выбери свой GitHub-аккаунт → разреши доступ

---

## ШАГ 3. Создание сервиса на Render

### 3.1. New Web Service

Dashboard → New (+) → Web Service

### 3.2. Выбери репозиторий

1. Поиск: `alisa-nevskaya-bot` (твой репозиторий)
2. Нажми Connect

### 3.3. Настройка сервиса

| Поле | Значение |
|---|---|
| **Name** | alisa-bot |
| **Region** | Frankfurt (ближе к Европе) |
| **Branch** | main |
| **Runtime** | Python 3 |
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `python bot_best.py` |
| **Plan** | **Starter** ← обязательно! диск есть только на платных |

### 3.4. Создай сервис

Нажми Create Web Service. Render начнёт билд.

---

## ШАГ 4. Добавь диск (Render Disk)

**Важно:** это делается ДО задания переменных.

### 4.1. В меню сервиса → Disks

1. Нажми Add Disk
2. Mount path: `/var/data`
3. Size: 1 GB
4. Нажми Create

Render перезагрузит сервис. Подожди 1–2 минуты.

---

## ШАГ 5. Переменные окружения

### 5.1. В меню сервиса → Environment

Добавь переменные (нажми Add Environment Variable):

| Key | Value |
|---|---|
| `TG_BOT_TOKEN` | **123456:ABC...** ← из @BotFather |
| `ADMIN_ID` | твой Telegram ID (узнай у @userinfobot) |
| `WEBHOOK_URL` | `https://alisa-bot.onrender.com` ← будет автоматически, но впиши вручную |
| `DATA_DIR` | `/var/data` |
| `BOT_USERNAME` | `AlisaNevskaya_bot` ← своё имя бота |
| `BACKUP_EVERY_HOURS` | 168 |
| `PORT` | 5000 |
| `ANTHROPIC_API_KEY` | (опционально, если используешь Claude) |

Для ANTHROPIC_API_KEY:
- Если будешь использовать Claude: скопируй ключ из console.anthropic.com
- Если нет: оставь пусто, помощник будет отключён

### 5.2. Сохрани

После добавления всех переменных нажми Save Changes.

Render перезагрузит сервис.

---

## ШАГ 6. Установи вебхук

После перезагрузки перейди в браузер:

```
https://alisa-bot.onrender.com/setwebhook
```

Должно вывести:
```
✅ Webhook установлен
```

Если ошибка — значит переменные не подхватились. Жди 1–2 минуты и повтори.

## ШАГ 7. Проверка здоровья

### 7.1. Проверь статус бота

```
https://alisa-bot.onrender.com/health
```

Должен вернуться JSON с такой структурой:

```json
{
  "status": "ok",
  "writable": true,
  "persistent": true,
  "orders": 0,
  "time": "2026-09-01T12:34:56.123456+03:00"
}
```

**Ключевые поля:**
- `"writable": true` — диск доступен
- `"persistent": true` — диск постоянный (не временный)

Если одно из них `false` → что-то не так с диском, проверь шаг 4.

### 7.2. Тест бота

Открой Telegram, найди своего бота в поиске или по ссылке `t.me/AlisaNevskaya_bot`

Отправь `/start`

Должно прийти приветствие с кнопками:
```
💌 <b>Алиса Невская</b>

Привет! Я пишу письма о том, что волнует.
Не советы — разговор.

⭐ 4.8 из 5 · письма получили 234 человека
Письмо от 390₽, готово за 24–48 часов.
```

И кнопки внизу:
- 💌 Заказать письмо
- 📖 Примеры
- 👤 Мой кабинет
- и т.д.

Если кнопок нет → прочитай логи (см. шаг 8).

## ШАГ 8. Логирование и отладка

### 8.1. Смотри логи в реальном времени

В меню сервиса на Render:
- Вкладка Logs
- Там видишь весь вывод бота

Если ошибки:
- `ModuleNotFoundError: No module named 'anthropic'` → requirements.txt не установился, проверь файл
- `NameError: name 'bot' is not defined` → пустой TG_BOT_TOKEN
- `Bad Request: can't parse entities` → HTML-проблема в имени клиента (должна обработаться автоматически)

### 8.2. Развёртывание логирования

В `bot_best.py` уже есть:
```python
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s | %(levelname)s | %(message)s",
)
```

Всё, что логируется с `log.info()`, будет видно в логах Render.

## ШАГ 9. Первый реальный тест

### 9.1. Заказ со второго аккаунта

1. Создай второй Telegram-аккаунт (или попроси друга)
2. Найди бота
3. Нажми `💌 Заказать письмо`
4. Выбери формат `💌 Письмо`
5. Напиши вопрос (минимум 15 символов)
6. На экране резюме нажми `💳 Оплатить`
7. Платишь 1 звезду Telegram (реальные деньги, но символическая сумма)

### 9.2. Проверь в админ-панели

От первого аккаунта (ADMIN_ID) жди сообщение:
```
🆕 Заказ создан (ждёт оплаты)

[Имя клиента]
💌 ПИСЬМО · 390₽
ALI-1234567890
```

После оплаты придёт:
```
💳 ОПЛАЧЕНО

[Имя клиента]
💌 ПИСЬМО · 390₽
Срок: до 01.09 в 14:48 МСК

Вопрос: [текст вопроса]

ALI-1234567890
```

Нажми кнопку `✍️ Написать письмо`.

### 9.3. Отправь письмо

Нажми `🔍 Разобрать вопрос` (если Claude подключён) или сразу пиши текст.

Скопируй-вставь свой текст письма одним сообщением (400–600 слов).

Письмо уходит клиенту, заказ переходит в статус `done`.

## ШАГ 11. Обновления кода

Когда будешь делать изменения:

```bash
git add .
git commit -m "Описание изменения"
git push origin main
```

Render автоматически заметит пуш → перестроит и переблагодарит сервис.

Это займёт 2–3 минуты. Во время перестройки бот будет недоступен 10–20 секунд.

## 🔧 Если что-то упало

| Проблема | Решение |
|---|---|
| Бот не отвечает на /start | Проверь TG_BOT_TOKEN в переменных |
| Ошибка про диск | DATA_DIR должен быть `/var/data`, диск должен существовать (шаг 4) |
| HTML-ошибки в сообщениях | Нормально, автоматически повторяются без разметки. Смотри логи |
| Облако Google Sheets в ошибке | Это из старой версии. Убедись, что запущен `bot_best.py`, не `bot_full_code.py` |
| Странные платежи или команды | Перепроверь, что на сервер загрузился нужный репозиторий. Иногда Render цепляется к старой версии |
